## 一、现状病根清单（必须 100% 根除）

1. **反等宽微软雅黑排版**：`--font-mono: var(--font-sans)` 令日志、PID、路径、命令与数字模糊粘连，且微软雅黑缺失 500/600 字重。
2. **严重对比度与缺失样式 Bug**：
   - 深色模式下 `.btn` 仅过渡背景不随主题切文字色，导致次级按钮出现白底浅灰字白闪失效；`.source-tab-btn.is-active` 深色为白字配浅蓝底（对比度 ~2.1:1 不合格）。
   - `EvidenceDrawer` 全部证据卡片、`SettingsModal` 启用按钮、`AutoStartPanel` 已启动徽章、`LogConsole` 状态横幅等 **40+ CSS 类在 `style.css` 中完全缺失**，且 `LogConsole` 内联引用了不存在的 `--color-bg-warning` 变量。
3. **扁平混沌表面与丑陋原生 Chrome**：深色画布 `#1c1d20` 与面板 `#202125` 几乎无区分；浅色通体惨白无层次；生命周期徽章无胶囊底色；弹窗内嵌粗笨浅灰 Windows 原生滚动条；Electron 顶部原生白色标题栏与深色界面割裂。
4. **主题耦合布局突变与巨大死空洞**：浅色横排、深色强拉右栏两行，导致单卡任务右侧出现 70% 黑洞空白并挤压日志；固定像素行高导致出现自动启动面板后，日志控制台直接被挤出首屏。
5. **数据可视化极度贫瘠**：主窗口用 CSS 把 `.gpu-memory-meter` 裁剪隐藏（宿主首页完全无显存条！）；全应用零 Sparkline、零 Loss/LR/GPU 趋势图；0% 与 100% 同色无负载色阶；独立 GPU 窗口最大化后 65% 以上留白。
6. **四重冗余头部与粗糙交互**：顶栏、侧栏、60px 连接条、页面标题四处重复显示同一宿主名；侧栏出现 `本地 WSL WSL` 重复文案；悬停 `...` 菜单与 `Ctrl+1` 快捷键重叠碰撞；底部残留死按钮 `进程监控`；自动启动表单 13 字段平铺截断路径；删除宿主无二次确认直接级联删任务；936 行追加覆盖式 `style.css` 存在 50+ 重复选择器与 8 处 `!important`；20 个手写粗糙图标混杂 Unicode 字符。

## 二、全新视觉设计系统（Design System Spec — 严格落地）

> **设计审美原则**：克制而精准的精密仪器美学。不要花哨渐变背景、不要彩虹霓虹、不要过度阴影、不要 AI 模板化的全大写跟踪眉标（ALL-CAPS eyebrow）。把视觉张力集中在**清晰的表面明度层级、锋利的排版数值对齐、克制的语义状态色阶与高信噪比实时图表**上。

### 1. 字体与排版体系（推翻旧版 `DESIGN.md` 反等宽禁令）

- **本地离线打包字体**（放入 `src/renderer/assets/fonts/`，在 `tokens.css` 用 `@font-face` 加载，100% 满足 `default-src 'self'` 离线 CSP）：
  - 无衬线拉丁与数字：`Inter`（400 / 500 / 600 / 700 WOFF2）
  - 等宽技术字体：`JetBrains Mono`（400 / 500 / 600 WOFF2）
  - 字体栈：
    - `--font-sans: 'Inter', 'PingFang SC', 'Noto Sans SC', 'Microsoft YaHei UI', system-ui, sans-serif;`
    - `--font-mono: 'JetBrains Mono', 'Cascadia Mono', 'Consolas', monospace;`
- **严格分工**：
  - 所有 **日志正文、时间戳、PID、文件路径、Checkpoint 文件名、CLI/tmux 命令、主机地址、GPU 显存/温度/功耗与 Loss/LR/Step 遥测读数** 均使用 `--font-mono` + `font-variant-numeric: tabular-nums`。
- **5 级清晰字号体系**：
  - Page Title：`20px / 600 / -0.02em`
  - Hero KPI Numeral：`22px–24px / 600 / -0.025em`（tabular-nums）
  - Section Heading：`14px / 600`
  - Body / Control：`13px / 400–500 / lh 1.45`
  - Meta / Caption / Log：`12px / 400–500`（日志行号与时间戳 `11.5px`）
