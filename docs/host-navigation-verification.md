# 宿主切换与连接验收

日期：2026-11-05。界面沿用已选定的浅色与石墨灰主题；此区域为 Operate 模式，优先让用户明确当前宿主、连接结果和可执行的下一步。

## 最终行为

- 侧栏宿主标题、宿主 ID 和顶部宿主按钮均可切换。没有任务的宿主仍能选中；内容区不会借用其他宿主的任务。
- 各宿主分别记住最近选择的任务；任务点击和 Ctrl+1～9 会同步切换所属宿主。初始快照延迟返回时保留用户刚选择的宿主。
- 当前宿主的状态栏提供连接、重新连接或检查连接。等待期间防止重复请求，结果采用后端实际探测；失败提示保留重试入口。停用的宿主引导到设置启用。
- 添加任务默认选择当前宿主。任务保存后切换到新任务及其宿主。
- 采集器独立探测所有已启用宿主，即使任务数为 0。按 hostId 刷新只探测指定宿主；单宿主失败不阻断其他宿主。连接结果不依赖虚构任务或旧任务缓存。

## 连接原因与实际结果

用户当前登记版本为 7，两个宿主均启用，任务数为 0。旧采集逻辑因宿主没有任务而跳过探测，是界面连接状态不能更新的原因之一；现已修复。

- lab-campus：已连接，fresh，最近探测约 537ms。

这验证了宿主连接与整卡探测；当前没有登记任务，因此不声称完成了 WSL 训练任务的端到端验证。
